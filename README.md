# CRM Reimagined

Ты работаешь над crm.
Первые три скришнота это наш текущий дизайн.
Четвертый скриншот это старая страница "Импорт".
Пятый скриншот это старая страница авторизации.
Шестой скриншот это старая страница бронирования для клиента.

Твоя задача сделать новые стильные, современные и функциональные страницы "авторизации", "импорта" и бронирования занятий.
Делай такие, что бы порвать рынок crm
Придерживайся нашего нового дизайна.
Все кнопки на этих страницах должны быть рабочими.
